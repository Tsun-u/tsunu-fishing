# 🎣 千望的怪怪釣魚日

一款輕鬆又有點荒唐的釣魚網頁小遊戲：看準魚漂咬鉤的瞬間收竿，把池塘裡各種怪魚帶回背包，慢慢填滿怪怪圖鑑。

**線上遊玩**：https://tsun-u.github.io/tsunu-fishing/

## 玩法

1. 點「拋竿」，耐心等魚漂傳來咬鉤訊號
2. 看到「咬鉤了！」立刻收竿；時機越準，遇見稀有怪魚的機會越高
3. 釣起來的魚可以放生，也可以收進背包
4. 在背包裡選擇怪魚出售，累積金幣
5. 打開圖鑑查看已發現的魚、釣獲次數與最大重量紀錄

池塘裡共有 10 種居民，從堅稱自己毫無怪癖的小鯽魚，到讓宇宙繞著牠旋轉的宇宙雞魚王都有。

## 特色

- 6 種稀有度、10 種原創怪魚與獨立圖鑑資料
- 收竿準度會影響稀有魚的出現機率
- 30 格背包，可單選、多選或一次出售全部漁獲
- 自動記錄圖鑑進度、釣獲次數與最大重量
- 支援滑鼠、觸控、空白鍵與 Enter 鍵操作
- 內建音效與裝置震動回饋，可隨時靜音
- 純前端零依賴，遊戲進度保存在瀏覽器裡

## 開發

單一 `index.html` 搭配 `assets/weird_fish_atlas.webp` 怪魚圖集，無建置步驟，clone 下來直接開啟 `index.html` 就能遊玩。
